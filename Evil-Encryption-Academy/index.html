Working tools, not pseudocode

Six programs, covered by 54 tests. Every test exists because a real bug shipped. The analysis tools are stdlib-only so they run on a locked-down forensic workstation with no package installs.

evidence ├─ identify_crypto.py what cipher? hybrid? statically linked? ├─ parse_footer.py encrypted at all? which paradigm? footer layout? ├─ recover_partial.py how much survived? extract it, offsets preserved └─ parse_footer.py run it again — an intact header means you got it right

identify_crypto.py

Sixty signatures: cipher constants, Windows crypto APIs, container magics, build toolchain. Refuses to draw a recoverability conclusion from filtered evidence.

parse_footer.py

Classifies the encryption paradigm and reconciles file format against extension — so it doesn't call every JPEG on your file server encrypted.

recover_partial.py

Extracts surviving plaintext with no key. Nulls damaged regions instead of removing them, so internal pointers still resolve.

canary_deploy.py

Decoy files that no legitimate process should touch. The one ransomware signal that needs no threshold and no tuning.

encryption_demo.py

Five demos that make entropy stop being abstract, plus safe practice specimens so you never need live malware.

Detection rules

YARA for cipher constants and embedded keys, Sigma for the anti-recovery behaviour that fires minutes before encryption starts.

What this is, and what it refuses to be

This is a read-side curriculum. It teaches you to recognise, analyse, detect and recover from ransomware encryption. It contains no ransomware.

Deliberately absent

  • Encryptor proof-of-concept code
  • File traversal and target selection
  • Backup and shadow-copy destruction
  • Throughput and evasion techniques

Fully covered

  • The cryptography itself, in full
  • Memory forensics and key recovery
  • Detection content and hunting guidance
  • Analysis, triage and recovery tooling

An incident responder never needs to write an encryptor, and the read-side skills are the ones that are actually scarce. The full reasoning is in SCOPE.md.
